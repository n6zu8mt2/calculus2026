3.7逆三角関数と atan2：向きから角度へ

この節のゴール
  1. $\sin^{-1},\ \cos^{-1},\ \tan^{-1}$ を「値の範囲を決めた逆関数」として説明できる。
  2. $\tan^{-1}\frac yx$ ではなく $\mathrm{atan2}(y,x)$ が必要な理由を説明できる。
  3. 角度の差を $-\pi$ から $\pi$ に折り返せる。

この節で使うこと：3.3節の 単位円、3.6節の グラフ、2.4節の「ひっくり返すと逆関数」

シューティングゲームで、敵の砲台がいつもプレイヤーの方を向いてくるのを見たことがあるでしょう。 プログラムがわかっているのは、砲台の座標とプレイヤーの座標、つまり2つの点の座標だけです。 ここから「砲台を何度に向ければいいか」を求めるには、三角関数とは逆向きの計算が必要です。

$$\underbrace{\text{角度 }\blue{\theta}\ \longrightarrow\ \text{向き }(\teal{\cos\theta},\ \red{\sin\theta})}_{\text{三角関数（3.3節）}}\qquad\qquad \underbrace{\text{向き }(\teal{x},\ \red{y})\ \longrightarrow\ \text{角度 }\blue{\theta}}_{\text{この節：逆三角関数・atan2}}$$

(1)三角関数をひっくり返す

2.4節では、$y=2^x$ を「$x$ について解く」ことで対数 $x=\log_2 y$ を作りました。$2^x=8$ なら $x=3$、という逆向きの計算です。 同じように、$y=\sin x$ を $x$ について解きたいと考えます。例えば

$$\red{\sin x}=\frac12\quad\text{となる }\blue{x}\text{ は？}$$

$30^\circ$ の三角定規から $\blue{x}=\frac{\pi}{6}$ が見つかります。でも、それだけではありません。 単位円で左右対称な $\frac{5\pi}{6}\,(=150^\circ)$ も $y$ 座標が $\frac12$ ですし、1周（$2\pi$）回った $\frac{13\pi}{6}$、$\frac{17\pi}{6}$、逆回りの $-\frac{7\pi}{6}$ なども全部そうです。 下の図で、グラフ $y=\red{\sin x}$ と横線 $y=k$ の交点を見てください。交点は無数にあります。

関数は「入れる値を1つ決めると、出てくる値が1つに決まる」ものでした（2.4節）。 ところが「$\sin x=\frac12$ となる $x$」は1つに決まらないので、このままでは関数として使えません。 グラフで言えば、$y=\sin x$ を直線 $y=x$ で折り返した形は、縦の線と何回も交わってしまうのです。

(2)値の範囲を決める

そこで、答えの角度の範囲を決めて、その中の1つだけを選ぶことにします。 $\sin$ なら、$-\frac{\pi}{2}$ から $\frac{\pi}{2}$（$-90^\circ$〜$90^\circ$、単位円の右半分）にしぼると、$-1$ から $1$ までのどの値もちょうど1回ずつとります。上の図の「範囲をしぼる」をオンにして確かめましょう。 こうして作った関数を $\sin^{-1}x$（アークサイン）と書きます。

$$\blue{\sin^{-1}\frac12}=\blue{\frac{\pi}{6}}\qquad\Longleftrightarrow\qquad \red{\sin}\frac{\pi}{6}=\frac12\ \text{ かつ }\ -\frac{\pi}{2}\leqq\frac{\pi}{6}\leqq\frac{\pi}{2}$$

$\cos$ と $\tan$ も同じように範囲を決めます。$\cos$ は右半分では $\pm$ の区別ができない（$\cos(-\theta)=\cos\theta$）ので、上半分 $0$〜$\pi$ にします。 $\tan$ は $\sin$ と同じ右半分ですが、真上・真下（$\pm\frac{\pi}{2}$）では $\tan$ がないので、端は入れません。

覚える｜逆三角関数の定義と値の範囲

「$\sin$ が $x$ になる角度」を、決めた範囲の中から1つ選ぶ

$\blue{\sin^{-1} x}$$\red{\sin y}=x$ となる $y$ のうち $-\frac{\pi}{2}\leqq y\leqq\frac{\pi}{2}$ のもの（$-1\leqq x\leqq1$）
$\blue{\cos^{-1} x}$$\teal{\cos y}=x$ となる $y$ のうち $0\leqq y\leqq\pi$ のもの（$-1\leqq x\leqq1$）
$\blue{\tan^{-1} x}$$\amber{\tan y}=x$ となる $y$ のうち $-\frac{\pi}{2}\lt y\lt\frac{\pi}{2}$ のもの（$x$ はどんな数でもよい）

$\sin^{-1}x$ は $\arcsin x$ とも書きます（プログラムでは asin, acos, atan）。$\sin^{-1}x$ は $\frac{1}{\sin x}$ ではありません（逆関数の記号 $f^{-1}$ の $-1$）。$\cos^{-1}x,\ \tan^{-1}x$ も同じで、$\arccos x,\ \arctan x$ とも書きます。

グラフも 2.4節と同じように、範囲をしぼった $y=\sin x$ を直線 $y=x$ で折り返すと $y=\sin^{-1} x$ になります。 関数を切りかえ、青い点をドラッグして確かめましょう。

値を求めるときは、「その三角関数の値になる角を、決めた範囲の中で探す」と考えます。単位円をかくと迷いません。

$$\begin{aligned} \sin^{-1}\frac12&=\frac{\pi}{6} &&\left(\sin\frac{\pi}{6}=\frac12,\ \ -\frac{\pi}{2}\leqq\frac{\pi}{6}\leqq\frac{\pi}{2}\right)\\ \cos^{-1}\left(-\frac12\right)&=\frac{2\pi}{3} &&\left(\cos\frac{2\pi}{3}=-\frac12,\ \ 0\leqq\frac{2\pi}{3}\leqq\pi\right)\\ \tan^{-1}1&=\frac{\pi}{4} &&\left(\tan\frac{\pi}{4}=1\right)\\ \tan^{-1}\sqrt3&=\frac{\pi}{3} &&\left(\tan\frac{\pi}{3}=\sqrt3\right) \end{aligned}$$

$\cos^{-1}\left(-\frac12\right)$ を $-\frac{2\pi}{3}$ としてはいけません。$\cos\left(-\frac{2\pi}{3}\right)=-\frac12$ ではありますが、$\cos^{-1}$ の範囲 $0$〜$\pi$ に入っていないからです。

(3)点 P の方向の角度：$\tan^{-1}$ と atan2

さて、砲台の問題にもどります。砲台を原点 $\mathrm{O}$ に置き、プレイヤーが点 $\mathrm{P}(\teal{x},\ \red{y})$ にいるとします。知りたいのは次のことです。

$$\text{点 }\mathrm{P}(\teal{x},\ \red{y})\text{ の方向の角度 }\blue{\theta}\text{ は？}\qquad\text{（}x\text{ 軸の正の向きから、反時計回りに測る）}$$

$\mathrm{O}$ と $\mathrm{P}$ で直角三角形をつくると、横の長さが $\teal{x}$、縦の長さが $\red{y}$ です。$\amber{\tan\theta}=\dfrac{\red{y}}{\teal{x}}$（傾き）なので、 $\theta=\tan^{-1}\dfrac{y}{x}$ で求まりそうです。たとえば $\mathrm{P}(3,\ 2)$ なら $\tan^{-1}\dfrac23\approx33.7^\circ$。これは正しい答えです。

では $\mathrm{Q}(-3,\ -2)$ はどうでしょう。$\dfrac{y}{x}=\dfrac{-2}{-3}=\dfrac23$ で、$\mathrm{P}$ とまったく同じ数になります。 $\tan^{-1}$ には $\dfrac23$ という1つの数しか渡らないので、答えも同じ $33.7^\circ$ です。 ところが図を見ると、$\mathrm{Q}$ は左下、$\mathrm{P}$ とはちょうど反対の方向にあります。

なぜこうなるのでしょう。$\tan^{-1}$ が見ているのは、割り算したあとの $\dfrac yx$ という1つの数だけです。 割り算すると、$x$ と $y$ の符号（$+$ か $-$ か）の情報が消えてしまいます。$\dfrac{-2}{-3}$ も $\dfrac{2}{3}$ も同じ $\dfrac23$ です。 これでは「右上」か「左下」かを区別できないので、$\tan^{-1}$ は（2）で決めたとおり、いつも右半分（$-90^\circ$〜$90^\circ$）の角を答えます。左半分の点では、180° ずれた反対向きになってしまうのです。

そこで、プログラムには $x$ と $y$ を割らずに、別々に受け取る関数 $\mathrm{atan2}(y,\ x)$ が用意されています。 $x$ と $y$ の符号を別々に見れば、点がどの場所（象限）にあるかがわかり、正しい方向の角度を $-180^\circ\lt\theta\leqq180^\circ$ で返してくれます。

割り算をしないので、$x=0$（真上・真下）でも困りません。 中では、左半分の点のとき $\tan^{-1}\dfrac yx$ の答えに $180^\circ$ を足したり引いたりして、反対向きを直しています。たとえば $\mathrm{Q}(-3,-2)$ なら $33.7^\circ-180^\circ=-146.3^\circ$ です。

どうして大事？：ゲームやロボットは「向き」から角度を出す

ゲームやロボットのプログラムでは、角度を「向き（ベクトル）$(x,\ y)$」から求める場面がたくさんあります。

  • 砲台：砲台 $(a,\ b)$ からプレイヤー $(p,\ q)$ への向き $(p-a,\ q-b)$ → 砲台を向ける角度。
  • キャラクターの向き：ジョイスティックを倒した向き $(x,\ y)$ → キャラが顔を向ける角度。
  • ロボットの進む向き：今いる場所から目的地への向き → ロボットが進む方角。

どれも、向きは上下左右どちらにもなります。右半分しか答えられない $\tan^{-1}\dfrac yx$ を使うと、相手が左側に来たとたんに反対を向くバグになります。 実際に見てみましょう。

砲台が $(a,b)$、プレイヤーが $(p,q)$ なら、向き $(p-a,\ q-b)$ を使って $\theta=\mathrm{atan2}(q-b,\ p-a)$。

(4)角度の差を折り返す

砲台やキャラクターを「一瞬で」ではなく、なめらかに回して目標の方へ向けたいとします。 今の向きが $350^\circ$、目標の向きが $10^\circ$ のとき、回す量（角度の差）をそのまま引き算すると

$$\Delta=\text{目標}-\text{今}=10^\circ-350^\circ=\amber{-340^\circ}\quad\text{（時計回りに 340°）}$$

となり、ほぼ1周の遠回りをしてしまいます。でも図をかけば、$350^\circ$ と $10^\circ$ は $0^\circ$ をはさんで $20^\circ$ しか離れていません。 下の2つの砲台を同じ速さで同時にスタートさせて、くらべてみましょう。

覚える｜角度の差の折り返し

差 $\Delta$ は $-180^\circ\lt\Delta\leqq180^\circ$ に直してから回す（近い方へ回る）

$$\Delta=\text{目標}-\text{今}\quad\longrightarrow\quad \begin{cases}\Delta\gt180^\circ\ \text{なら}\ \Delta-360^\circ\\ \Delta\leqq-180^\circ\ \text{なら}\ \Delta+360^\circ\\ \text{それ以外はそのまま}\end{cases}$$
  • $\Delta\gt0$ なら反時計回り、$\Delta\lt0$ なら時計回りに $|\Delta|$ 回す。
  • まとめて1行で書くと $\Delta\to\mathrm{atan2}(\sin\Delta,\ \cos\Delta)$。「$\Delta$ の向きの角度」を atan2 で $-180^\circ$〜$180^\circ$ に読み直している。
  • ラジアンでは $180^\circ=\pi$、$360^\circ=2\pi$。

使われている所：ゲームのキャラクターや砲台の向き、ロボットの旋回、方位磁針（北 $0^\circ$ をまたぐ方位 $350^\circ$ と $10^\circ$ の差は $20^\circ$）。

プログラムでは、次のように書けます。 

let d = target - angle;                   // 目標 − 今（ラジアン）
d = Math.atan2(Math.sin(d), Math.cos(d)); // −π〜π に折り返す
angle += Math.sign(d) * Math.min(Math.abs(d), speed * dt);  // 近い方へ少しずつ回す

(5)スマホで角度を測る

スマホの中には加速度センサーがあり、重力がスマホの横方向（$x$）と縦方向（$y$）にどれだけかかっているか $(\teal{g_x},\ \red{g_y})$ がわかります。 画面の中で「真下」がどちらの向きかは、この2つから $\mathrm{atan2}$ で求まります。画面の向きはどの向きにもなりうるので、$\tan^{-1}$ ではなく $\mathrm{atan2}$ が必要です。

$$\text{重力の向き }\blue{\theta}=\mathrm{atan2}(\red{g_y},\ \teal{g_x}),\qquad \text{机からの傾き }\varphi=\cos^{-1}(-g_z)$$

スマホをまっすぐ立てると重力は画面の真下なので $\theta=-90^\circ$。そこから何度回したかは $\theta+90^\circ$ です（水準器アプリはこれを表示しています）。 また、画面に垂直な方向の重力 $g_z$（重力の大きさを 1 とする）からは、$\cos\varphi=-g_z$ として机からの傾き $\varphi$ が $\cos^{-1}$ で求まります。$\varphi$ は $0$〜$\pi$ なので、$\cos^{-1}$ の範囲にちょうど合っています。

    $\cos y=-\dfrac12$、$0\leqq y\leqq\pi$ となる $y$ は、単位円の上半分で $x$ 座標が $-\dfrac12$ の点なので $\cos^{-1}\left(-\dfrac12\right)=\dfrac{2\pi}{3}$
    $\tan y=\sqrt3$、$-\dfrac{\pi}{2}\lt y\lt\dfrac{\pi}{2}$ となる $y$ なので $\tan^{-1}\sqrt3=\dfrac{\pi}{3}$
  2. $\tan\dfrac{\pi}{4}=1$ なので $\tan^{-1}1=\dfrac{\pi}{4}$
    上半分で $x$ 座標が $-\dfrac{\sqrt3}{2}$ の点は $\dfrac{5\pi}{6}\,(=150^\circ)$ なので $\cos^{-1}\left(-\dfrac{\sqrt3}{2}\right)=\dfrac{5\pi}{6}$
    右半分で $y$ 座標が $-\dfrac{\sqrt3}{2}$ の点は $-\dfrac{\pi}{3}$ なので $\sin^{-1}\left(-\dfrac{\sqrt3}{2}\right)=-\dfrac{\pi}{3}$
  3. 点 $(-1,\ -1)$ は第3象限で、$45^\circ$ の三角定規の形。$-\pi\lt\theta\leqq\pi$ で表すと $\mathrm{atan2}(-1,-1)=-\dfrac{3\pi}{4}\,(=-135^\circ)$
    点 $(-\sqrt3,\ 1)$ は第2象限で、$x$ 軸の負の向きから $30^\circ$ 上。$\mathrm{atan2}(1,-\sqrt3)=\pi-\dfrac{\pi}{6}=\dfrac{5\pi}{6}$
    点 $(0,\ -2)$ は真下なので $\mathrm{atan2}(-2,\ 0)=-\dfrac{\pi}{2}$（$\tan^{-1}\dfrac{-2}{0}$ は割り算できない）
    $\tan^{-1}\dfrac{-1}{-1}=\tan^{-1}1=\dfrac{\pi}{4}$ となり、本当の向き $-\dfrac{3\pi}{4}$ とちょうど反対向き（$\pi$ ずれる）になってしまう。
  4. $\Delta=30^\circ-340^\circ=-310^\circ$。$-180^\circ$ 以下なので $360^\circ$ 足して $\Delta=50^\circ$。反時計回りに $50^\circ$
    $\Delta=-\dfrac{3\pi}{4}-\dfrac{3\pi}{4}=-\dfrac{3\pi}{2}$。$-\pi$ 以下なので $2\pi$ 足して $\Delta=\dfrac{\pi}{2}$。反時計回りに $\dfrac{\pi}{2}\,(=90^\circ)$（$135^\circ$ から $225^\circ=-135^\circ$ へ）
