3.8波を足す：音・うなり・フーリエ

ピアノとバイオリンで同じ「ラ」をひいても、ちがう音に聞こえます。友だちの声は、顔を見なくてもだれの声かわかります。 この「音色（ねいろ）のちがい」はどこから来るのでしょうか。 この節では、音が $\sin$ の波であること、そして波を足し算すると、うなり・音の打ち消し・いろいろな音色が生まれることを、実際に音を鳴らしながら確かめます。

(1)音は $\sin$ の波

音は空気のふるえです。スピーカーの膜が前後にふるえると、空気が押されたり引かれたりして、そのふるえが耳まで伝わります。 膜の位置を、時刻 $t$（秒）を横軸にしてグラフにすると、音叉（おんさ）や時報の「ピッ」のような澄んだ音（純音）は、きれいな $\sin$ の波になります。

$$y=\violet{A}\sin(2\pi\amber{f}\,t)$$
  • $\violet{A}$（振幅）：ふるえの大きさ。大きいほど大きな音。
  • $\amber{f}$（周波数）：1秒間にふるえる回数。単位は Hz（ヘルツ）。大きいほど高い音。

なぜ $2\pi\amber{f}$ なのでしょう。3.5節の円運動で考えると、1秒に $\amber{f}$ 回転する点は、1秒に $2\pi\amber{f}$ ラジアン回ります。その影（縦の位置）が $\sin(2\pi\amber{f}t)$ です。 3.6節の $y=\sin Bx$ と同じ形で、$B=2\pi\amber{f}$ なので、周期は

$$T=\frac{2\pi}{2\pi\amber{f}}=\frac{1}{\amber{f}}\ \text{秒}$$

です。例えば、2.5節で見た基準の「ラ」は $\amber{f}=440$ Hz で、1回ふるえるのにかかる時間は $\frac{1}{440}\approx0.00227$ 秒（約 2.3 ミリ秒）。 1オクターブ上のラは周波数が2倍の 880 Hz、下のラは 220 Hz でした。人の耳に聞こえるのは、だいたい 20 Hz から 20000 Hz までです。

小話：コンセントの 100 V は、最大 141 V の sin の波

家のコンセントの電気も $\sin$ の波です（交流）。東日本では1秒に 50 回、西日本では 60 回、プラスとマイナスが入れかわります。 「100 V」は平均的な強さ（実効値）を表していて、波の山の高さは $100\sqrt2\approx141$ V です。東日本なら $\amber{f}=50$ なので

$$V=141\sin(2\pi\cdot50\,t)=141\sin(100\pi t)$$

と書けます。周波数が東西でちがうのは、明治時代に東京はドイツ製（50 Hz）、大阪はアメリカ製（60 Hz）の発電機を買ったからです。

小話：CD はなぜ 1 秒に 44100 回？

CD は、音の波の高さを1秒に 44100 回（44.1 kHz）測って、数の列として記録しています。 波を記録するには、1回のふるえの中で少なくとも2回（山と谷）は測らないといけません。人に聞こえるいちばん高い音は約 20000 Hz なので、その2倍の 40000 回より少し多い 44100 回にしたのです（標本化定理）。

(2)波を足す：うなりと逆位相

2つの音を同時に鳴らすと、空気のふるえは足し算になります。これを波の重ね合わせといいます。 周波数が少しだけちがう2つの音、例えば 440 Hz と 444 Hz を一緒に鳴らすと、「ワーン、ワーン」と音の大きさが周期的にゆれて聞こえます。これをうなりといいます。

山と山が重なるときは強め合い（大きな音）、少しずつずれて山と谷が重なるときは打ち消し合います（小さな音）。下の図で、2つの波 $\red{f_1}$、$\teal{f_2}$ を足した波（紫）の大きさがゆれる様子を見て、聞いてみましょう。

うなりの回数は $|f_1-f_2|$

3.5節の加法定理で、$\sin(\alpha+\beta)$ と $\sin(\alpha-\beta)$ を足すと、$\cos\alpha\sin\beta$ の項が打ち消し合って

$$\begin{aligned}&\sin(\alpha+\beta)+\sin(\alpha-\beta)\\&=2\sin\alpha\cos\beta\end{aligned}$$

となります。$\alpha+\beta=2\pi\red{f_1}t,\ \alpha-\beta=2\pi\teal{f_2}t$ とおくと $\alpha=\pi(\red{f_1}+\teal{f_2})t,\ \beta=\pi(\red{f_1}-\teal{f_2})t$ なので

$$\begin{aligned}&\red{\sin(2\pi f_1t)}+\teal{\sin(2\pi f_2t)}\\&=\amber{2\cos\bigl(\pi(f_1-f_2)t\bigr)}\cdot\sin\bigl(\pi(f_1+f_2)t\bigr)\end{aligned}$$

右の $\sin$ は、2つの音の真ん中の高さ $\frac{f_1+f_2}{2}$ の音。前の $\amber{2\cos(\cdots)}$ は、ゆっくり変わる「音の大きさ」（図の金色の点線）です。 大きさ $\amber{\bigl|2\cos(\pi(f_1-f_2)t)\bigr|}$ は $\frac{1}{|f_1-f_2|}$ 秒ごとにくり返すので、うなりは1秒に $|f_1-f_2|$ 回聞こえます。

ギターやオーケストラのチューニングでは、これを使います。基準の音（音叉の 440 Hz など）と弦を一緒に鳴らし、うなりがだんだんゆっくりになるように弦をしめたりゆるめたりして、うなりが消えたら同じ高さです。 2.5節の「平均律と純正律の差がうなりとして聞こえる」も、この現象です。

逆位相：波を打ち消す

今度は、周波数が同じでタイミング（位相）だけ $\teal{\varphi}$ ずれた2つの波を足してみます。3.6節の合成と同じように計算すると

$$\begin{aligned}&\red{\sin x}+\violet{\sin(x+\varphi)}\\&=2\cos\frac{\teal{\varphi}}{2}\cdot\sin\left(x+\frac{\teal{\varphi}}{2}\right)\end{aligned}$$

となり、和の振幅は $\left|2\cos\frac{\teal{\varphi}}{2}\right|$ です。$\teal{\varphi}=0$ なら2倍に強め合い、$\teal{\varphi}=\pi$（半周期ずれ）なら $\cos\frac{\pi}{2}=0$ で、和はぴったり 0。音が消えます。 山と谷がちょうど逆になっているこの状態を逆位相といいます。

「左右の耳に分ける」にすると、$\red{\sin x}$ は左、$\violet{\sin(x+\varphi)}$ は右のスピーカーから出ます。ヘッドホンでは2つの音が空気の中で足されないので、$\teal{\varphi}=\pi$ でも消えません（聞こえ方が少し変わるだけ）。 音を打ち消すには、同じ場所で足し合わされることが必要です。

これを使うのがノイズキャンセリングのヘッドホンです。ヘッドホンについた小さなマイクで周りの騒音を拾い、それと逆位相の音をスピーカーから出して、耳の中で騒音を打ち消します。 電車のゴーッという低い音のように、ゆっくり変わる音ほど、逆位相の音を作るのが間に合うので、よく消えます。

覚える｜波の重ね合わせ

同時に鳴る音は足し算。ずれ方で強め合ったり打ち消し合ったりする

$$\begin{gathered}\text{うなりの回数（1秒あたり）}=|f_1-f_2|\\[4pt] \sin x+\sin(x+\varphi)\\=2\cos\frac{\varphi}{2}\,\sin\left(x+\frac{\varphi}{2}\right)\end{gathered}$$
  • 周波数が近い2つの音 → 大きさが $|f_1-f_2|$ 回/秒 でゆれる（うなり）
  • 同じ周波数で $\varphi=\pi$ ずれた波（逆位相）を足すと 0 になる（ノイズキャンセリング）

例：440 Hz と 443 Hz → 1秒に3回うなる。うなりが消えたら2つの音は同じ高さ。

(3)フーリエ級数

楽器の音を波形にすると、純音のようなきれいな $\sin$ ではなく、もっと複雑な形をしています。でも、形はちがっても同じ形をくり返す（周期的）ことは同じです。 フランスのフーリエ（1768–1830）は、次のことを見つけました。

$$\begin{aligned}&\text{周期的な波}\\&=b_1\sin x+b_2\sin2x+b_3\sin3x+\cdots\end{aligned}$$

つまり、くり返す波はどれも、周期が $\frac{1}{1},\ \frac{1}{2},\ \frac{1}{3},\ \ldots$ の $\sin$（や $\cos$）を、ちょうどよい大きさ $b_1,\ b_2,\ b_3,\ \ldots$ で足し合わせたものとして表せる、ということです（$\cos$ の項が必要な波もあります）。これをフーリエ級数といいます。 ここでは周期が $2\pi$ になるように $x$ を使って書きます（音にするときは $x$ を $2\pi ft$ に置きかえます）。

音でいうと、$\sin x$ は基本の高さ $f$ の音、$\sin2x$ は2倍の $2f$（1オクターブ上）、$\sin3x$ は $3f$ の音……で、これらを倍音といいます。 倍音をどんな大きさで混ぜるかが、音色のちがいの正体です。昔のゲーム機の「ピコピコ音」は、下の矩形波（くけいは）で作られていました。

ギブズ現象：角の近くの「飛び出し」は消えない

矩形波やのこぎり波のように、値がとぶ（角がある）ところでは、部分和が目標より約 9% 飛び出します（矩形波では高さ 1 のところが約 1.18 になる）。 $N$ を増やすと飛び出す部分はどんどん細くなりますが、高さはなくなりません。これをギブズ現象といいます。 画像を強く圧縮したとき、文字のまわりにもやもやしたすじが出るのも、同じ理由です。

覚える｜フーリエ級数の考え方

くり返す波は、$\sin nx$（倍音）の足し算で表せる

$$\text{波}=b_1\sin x+b_2\sin2x+b_3\sin3x+\cdots$$
  • $\sin nx$ は基本の $n$ 倍の周波数の音（倍音）。倍音の混ぜ方 $b_1,\ b_2,\ \ldots$ が音色を決める
  • 矩形波 $=\dfrac{4}{\pi}\left(\sin x+\dfrac{\sin3x}{3}+\dfrac{\sin5x}{5}+\cdots\right)$（奇数倍音だけ）

係数 $b_n$ を求めるには積分を使う（積分の章で）。項を増やすほど近づくが、角の近くでは約 9% の飛び出しが残る（ギブズ現象）。

(4)回転円で描く

3.5節で、回る円の上の点の「縦の影」は $\sin$ の波になることを見ました。 では、$\frac{4}{\pi}\left(\sin x+\frac{\sin3x}{3}+\cdots\right)$ のような足し算は？ 半径 $\frac{4}{\pi}$ の円の上を回る点に、半径 $\frac{4}{3\pi}$ で3倍の速さで回る小さな円をつけ、その上にさらに半径 $\frac{4}{5\pi}$ で5倍の速さの円をつけ……と、円の先に円をつないでいきます。 いちばん先の点の高さは、それぞれの円の高さの足し算なので、ちょうど部分和になります。その高さを右へ記録していくと、矩形波が描けます。

(5)自分の声・自分の絵を分解する

自分の声を倍音に分ける

今度は反対に、音を倍音に分解してみましょう。マイクで拾った音を、コンピュータがその場で「どの周波数の $\sin$ がどれだけ入っているか」に分けます（フーリエ変換）。 「あー」と「いー」を同じ高さで言ってみると、いちばん下の山（基本の高さ $f_0$）の位置は同じなのに、$2f_0,\ 3f_0,\ \ldots$ の倍音の山の大きさがちがうはずです。これが「あ」と「い」の音色のちがいです。 口笛は倍音が少なく、純音に近い1本の山になります。

    (b) $|440-f|=3$ より $440-f=3$ または $440-f=-3$。よって $f=437$ Hz または $443$ Hz。
    （どちらかは、弦を少ししめて高くしたときにうなりが速くなるか遅くなるかで見分けられる。）
  4. $\sin\dfrac{\pi}{2}=1$、$\sin\dfrac{3\pi}{2}=-1$、$\sin\dfrac{5\pi}{2}$ $=\sin\left(2\pi+\dfrac{\pi}{2}\right)=1$ なので
    $\dfrac{4}{\pi}\left(1-\dfrac13+\dfrac15\right)$ $=\dfrac{4}{\pi}\cdot\dfrac{15-5+3}{15}$ $=\dfrac{4}{\pi}\cdot\dfrac{13}{15}$ $=\dfrac{52}{15\pi}\approx1.10$
    本当の値 $1$ より約 $0.10$ 大きい（3項ではまだ山の上が波打っている）。項を増やすと $x=\dfrac{\pi}{2}$ での値は $1$ に近づく（$1-\frac13+\frac15-\frac17+\cdots=\frac{\pi}{4}$ だから）。
