(1)累乗（るいじょう）とは：同じ数を何回かけるか

同じ数を何回もかけるとき、かけ算を全部書くと長くなります。そこで、かける回数を右上に小さく書くことにします。

$$2^{\red{3}}=\underbrace{2\times2\times2}_{\red{3}\ \text{個かける}}=8$$

$2^3$ は「2 の 3 乗」と読みます。右上の小さい数 $\red{3}$ を指数（しすう）、もとの数 $2$ を底（てい）といいます。 一般に、$a$ を $\red{n}$ 個かけたものを $a^{\red{n}}$ と書きます。

覚える｜累乗の意味
$$a^{n}=\underbrace{a\times a\times\cdots\times a}_{a\ \text{を}\ n\ \text{個かける}}$$
書き方読み方意味値
$2^1$2 の 1 乗$2$（2 が 1 個だけ）$2$
$2^2$2 の 2 乗$2\times2$$4$
$2^3$2 の 3 乗$2\times2\times2$$8$
$2^4$2 の 4 乗$2\times2\times2\times2$$16$
$3^2$3 の 2 乗$3\times3$$9$
$10^3$10 の 3 乗$10\times10\times10$$1000$

では $2^0$（0 個かける？）や $2^{-1}$（−1 個かける？）、$2^{\frac12}$（半分個かける？）はどうでしょう。 「かける個数」として考えると意味がわかりません。この節では、すでに成り立っている規則がそのまま成り立つように意味を広げると、 $2^0=1$、$2^{-1}=\frac12$、$2^{\frac12}=\sqrt2$ とごく自然に決まってしまうことを見ていきます。

(3)指数法則とは

もう一つの見方に進む前に、指数法則を確認しておきましょう。指数が 1, 2, 3, … のときに成り立つ、計算のきまりです。

きまり①　かけ算は、指数のたし算

$$\begin{aligned}a^{\teal{m}}\times a^{\red{n}}&=(\teal{a\ \text{を}\ m\ \text{個かける}})\times(\red{a\ \text{を}\ n\ \text{個かける}})\\&=(a\ \text{を}\ \teal{m}+\red{n}\ \text{個かける})=a^{\teal{m}+\red{n}}\end{aligned}$$
$$\text{例：}2^{\teal{3}}\times2^{\red{2}}=(\teal{2\times2\times2})\times(\red{2\times2})=2^{\teal{3}+\red{2}}=2^5=32$$

きまり②　累乗の累乗は、指数のかけ算

$$\begin{aligned}\left(a^{\teal{m}}\right)^{\red{n}}&=(\teal{a\ \text{を}\ m\ \text{個かけたもの}})\ \text{を}\ \red{n}\ \text{個かける}\\&=(a\ \text{を}\ \teal{m}\times\red{n}\ \text{個かける})=a^{\teal{m}\red{n}}\end{aligned}$$
$$\text{例：}\left(2^{\teal{3}}\right)^{\red{2}}=(\teal{2\times2\times2})\times(\teal{2\times2\times2})=2^{\teal{3}\times\red{2}}=2^6=64$$

きまり③　わり算は、指数のひき算

（$m$ が $n$ より大きいとき）

$$\frac{a^{\teal{m}}}{a^{\red{n}}}=a^{\teal{m}-\red{n}}\qquad\text{例：}\ \frac{2^5}{2^2}=\frac{2\times2\times\cancel{2}\times\cancel{2}\times\cancel{2}}{\cancel{2}\times\cancel{2}}=2^3=2^{5-2}$$
覚える｜指数法則
$$\begin{gathered}a^{m}\times a^{n}=a^{m+n}\\[4pt] \left(a^{m}\right)^{n}=a^{mn}\\[4pt] \frac{a^{m}}{a^{n}}=a^{m-n}\end{gathered}$$

(4)指数法則を守ると、0 乗と負の指数が決まる

$2^0$ や $2^{-3}$ の値は、まだ決まっていない「空いている席」です。そこに入れる値は、 指数法則のきまり① $a^m\times a^n=a^{m+n}$ が 0 や負の数でもそのまま成り立つように選ぶことにします。 （「この場合は例外…」と気をつけなくてよいので、計算がずっと楽になります。）

ステップ1：$2^0$ を決める。

きまり① $a^m\times a^n=a^{m+n}$ で $m=0,\ n=3$ とすると

$$2^{0}\times2^{3}=2^{0+3}=2^3\qquad\text{つまり}\qquad 2^0\times8=8$$

「8 にかけても 8 のまま」になる数は $1$ だけ。だから $2^0=1$ と決めるしかありません。

ステップ2：$2^{-3}$ を決める。

きまり① $a^m\times a^n=a^{m+n}$ で $m=-3,\ n=3$ とすると

$$2^{-3}\times2^{3}=2^{-3+3}=2^0=1\qquad\text{つまり}\qquad 2^{-3}\times8=1$$

「8 にかけると 1 になる数」は $\dfrac18$ だけ。だから $2^{-3}=\dfrac18=\dfrac1{2^3}$。(2) のパターンで決めた値とまったく同じです。

こうして、(2) で覚えた $a^0=1,\ a^{-n}=\dfrac1{a^n}$ が、指数法則からも同じように決まることがわかりました。

ステップ3：負の指数でも、指数法則がちゃんと成り立つか確かめる。

$a^{\red{n}}$ は「1 から始めて ×$a$ を $n$ 回」、$a^{-n}=\dfrac1{a^n}$ は「1 から始めて ÷$a$ を $n$ 回」と考えられます。 すると、×$a$ と ÷$a$ が出会うと打ち消し合うので、残った個数がそのまま指数になります。例えば

$$2^{5}\times2^{-2}=\frac{2\times2\times2\times\cancel{2}\times\cancel{2}}{\cancel{2}\times\cancel{2}}=2^3=2^{5+(-2)}$$
$$2^{-1}\times2^{-2}=\frac12\times\frac14=\frac18=2^{-3}=2^{(-1)+(-2)}$$

きまり② $\left(a^m\right)^n=a^{mn}$ も $\left(2^{-1}\right)^2=\left(\dfrac12\right)^2=\dfrac14=2^{-2}=2^{(-1)\times2}$ のように成り立ちます。下の図で、いろいろな組み合わせを試してみましょう。

×2 と ÷2 の打ち消し合い ＋／− で $m,\ n$ を変える

$2^{m}$ は「1 に ×2 を $m$ 回」（$m$ が負のときは ÷2 をくり返す。例：$2^{-2}$ は「1 に ÷2 を 2 回」）と考えます。 $2^{\teal{m}}\times2^{\red{n}}$ では ×2 と ÷2 が打ち消し合い、残った個数が指数 $\teal{m}+\red{n}$ になる ことを確かめましょう。

(5)n 乗根：n 回かけると a になる数

分数の指数の前に、ルート（平方根）を思い出しましょう。$\sqrt{a}$ は「2 乗すると $a$ になる正の数」でした。 例：$\sqrt9=3$（$3^2=9$）、$\sqrt2\approx1.414$（$1.414^2\approx2$）。

同じように考えて、次のように決めます。

覚える｜n 乗根
$$\sqrt[n]{a}=(n\ \text{乗すると}\ a\ \text{になる正の数})\qquad(a>0)$$

「$a$ の $n$ 乗根」と読みます。$n=2$ のときがふつうのルート（$\sqrt[2]{a}=\sqrt a$ と書く）。 例：$\sqrt[3]{8}=2$（$2^3=8$）、$\sqrt[4]{16}=2$（$2^4=16$）、$\sqrt[3]{2}\approx1.26$（$1.26^3\approx2$）。

グラフで見ると、$\sqrt[n]{a}$ は曲線 $y=x^n$ と横線 $y=a$ が交わる点の $x$ 座標です。$x\geqq0$ で $y=x^n$ は右上がりなので、交わる点はちょうど1つ。だから $\sqrt[n]{a}$ はちゃんと1つに決まります。

(6)分数の指数

では $2^{\frac12}$ は何でしょう。ここでも、指数法則のきまり②（累乗の累乗は、指数のかけ算）

$$\left(a^{m}\right)^{n}=a^{m\times n}$$

が、指数が分数でもそのまま成り立つように決めます。$a=2,\ m=\frac12,\ n=2$ とすると

$$\left(2^{\frac12}\right)^2=2^{\frac12\times2}=2^1=2$$

つまり $2^{\frac12}$ は「2 乗すると 2 になる数」＝ $\sqrt2$。同じように $\left(2^{\frac13}\right)^3=2^1=2$ なので $2^{\frac13}=\sqrt[3]{2}$。一般に

覚える｜分数の指数
$$a^{\frac1{n}}=\sqrt[n]{a},\qquad a^{\frac{m}{n}}=\left(\sqrt[n]{a}\right)^{m}$$

分母 $\red{n}$ は「何乗根か」、分子 $\teal{m}$ は「それを何乗するか」を表します。 例：$8^{\frac23}=\left(\sqrt[3]{8}\right)^2=2^2=4$、　$4^{\frac32}=\left(\sqrt4\right)^3=2^3=8$、　$27^{-\frac13}=\dfrac{1}{27^{\frac13}}=\dfrac1{\sqrt[3]{27}}=\dfrac13$。

分数の指数でも指数法則は成り立ちます。例えば $2^{\frac13}\times2^{\frac23}$ $=\sqrt[3]{2}\times\sqrt[3]{4}$ $=\sqrt[3]{8}=2=2^1$ で、指数のたし算 $\frac13+\frac23=1$ と合っています。

発展：どうしていつも成り立つの？

2つの分数の指数を通分して $\dfrac{p}{q}$ と $\dfrac{r}{q}$ にし、$b=a^{\frac1q}=\sqrt[q]{a}$ とおくと $a^{\frac pq}=b^p,\ a^{\frac rq}=b^r$ です。すると

$$a^{\frac pq}\times a^{\frac rq}=b^{p}\times b^{r}=b^{p+r}=a^{\frac{p+r}{q}}=a^{\frac pq+\frac rq}$$

となり、整数の指数の法則に帰着します。「$\frac1q$ 乗」を1歩とみて、その歩数を数えているだけなのです。
