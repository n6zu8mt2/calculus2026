第1回 ／ 多項式

多項式を「動かして」理解する

多項式 $a_n x^n + \cdots + a_1 x + a_0$ は、いちばん身近で、いちばん使い道の広い関数です。 次数を1つずつ上げながら、「まっすぐ」→「曲がる」→「なめらかに加速・減速する」→「思い通りの曲線を描く」→「データを通る曲線を作る」へ進みます。 図の中の 丸いつまみ はドラッグでき、スライダー でも同じ操作ができます。 文章・数式・図・スライダーで同じ色が同じ量を表す ので、色をたどって対応を確かめてください。

1.22点から直線を作る ― 補間（lerp）

2点 $\boldsymbol{A}$, $\boldsymbol{B}$ が決まると直線が1本決まります。 パラメータ $t$ を使って、線分 $\boldsymbol{A}\boldsymbol{B}$ 上の点 $\boldsymbol{P}(t)$ を次のように定めます。

$$\boldsymbol{P}(t) = (1-t)\,\boldsymbol{A} + t\,\boldsymbol{B}\qquad (0\leqq t\leqq 1)$$
  • $t=0$ のとき $\boldsymbol{P}(0)=\boldsymbol{A}$、$t=1$ のとき $\boldsymbol{P}(1)=\boldsymbol{B}$。
  • $t$ を $0$ から $1$ へ動かすと、$\boldsymbol{P}(t)$ は $\boldsymbol{A}$ から $\boldsymbol{B}$ まで 一定の速さ で進む（$t$ の1次式なので）。
  • $\boldsymbol{P}(t)-\boldsymbol{A}=t(\boldsymbol{B}-\boldsymbol{A})$ なので、 $\overline{\mathrm{AP}}=t\,\overline{\mathrm{AB}}$、 $\overline{\mathrm{PB}}=(1-t)\,\overline{\mathrm{AB}}$。 つまり $\mathrm{AP}:\mathrm{PB}=t:(1-t)$（線分 $\mathrm{AB}$ を $t:(1-t)$ に 内分 する点）。

この「$t:(1-t)$ に分ける」操作が、あとで登場するベジェ曲線のすべての土台になります。

2二次関数

$y = ax^2 + bx + c$（$a\neq 0$）のグラフは 放物線 です。直線と違って「曲がる」ので、 頂点（いちばん高い／低いところ）と 対称軸 が現れます。 まず最も単純な $y=x^2$ を出発点にして、それを動かす方法（平行移動）から見ていきます。

2.1グラフを平行移動する

グラフ $y=f(x)$ を、$x$ 方向に $p$、$y$ 方向に $q$ だけ動かします（右・上が正）。 このとき動かしたグラフの式は、もとの式の $x$ を $x-\teal{p}$ に、$y$ を $y-\red{q}$ に置き換えたものになります。

$$y=f(x)\quad\xrightarrow{\ x\text{方向に}\ \teal{p},\ y\text{方向に}\ \red{q}\ }\quad y-\red{q}=f(x-\teal{p})$$

$f(x)=x^2$ なら、$y-\red{q}=(x-\teal{p})^2$、つまり $y=(x-\teal{p})^2+\red{q}$ で、頂点は $(0,0)$ から $(\teal{p},\ \red{q})$ に動きます。

3イージング

アプリの画面で物が滑らかに動くとき、その動きは「時間 $t$ ($0\to1$) から、位置（進み具合）$f(t)$ ($0\to1$) への関数」で決まっています。 これを イージング関数 といいます。$f(t)=t$（一次関数）は 等速 ですが、機械的で不自然です。 2次・3次の多項式を使うと、ゆっくり動き出す（ease-in）、ゆっくり止まる（ease-out） 動きが作れます。

4ベジェ曲線

1.2節の補間 $\boldsymbol{P}(t)=(1-t)\boldsymbol{A}+t\boldsymbol{B}$ を 繰り返す と曲線が生まれます。 制御点 $\boldsymbol{P}_0,\dots,\boldsymbol{P}_n$ があるとき、次の操作を1点になるまで続けます（ド・カステリョのアルゴリズム）。

操作：隣り合う2点を $t:(1-t)$ に内分して、点を1つ減らす

隣り合う2点 $\boldsymbol{X},\boldsymbol{Y}$ に対し、$\boldsymbol{X}$ からの距離が全体の $t$ 倍の点、つまり $(1-t)\boldsymbol{X}+t\boldsymbol{Y}$ を作ります。線分 $\boldsymbol{X}\boldsymbol{Y}$ は $\boldsymbol{X}$ 側の長さ $=t$（赤）と $\boldsymbol{Y}$ 側の長さ $=1-t$（青緑）に分かれます。 どの線分でも、同じ $t$ で同じ比に分けます。

4.11次から3次のベジェ曲線：$t:(1-t)$ がどこに現れるか

まずは1次から3次まで、それぞれ図で確かめましょう。図ごとに再生／停止と $t$ のスライダー があります。 $t$ を動かすと、すべての線分が赤と青緑に 同じ比 $t:(1-t)$ で分かれることが見えます。 内分を重ねるほど、線は 細く薄く 描いています（薄い線ほど後の段）。点はドラッグできます。

$\boldsymbol{P}_0\boldsymbol{P}_1$ を $t:(1-t)$ に内分した点が $\boldsymbol{P}(t)$。1.2節の補間そのものです。

2次ベジェ曲線（点3個）：内分を2段重ねる

1段目：$\boldsymbol{P}_0\boldsymbol{P}_1$ を $t:(1-t)$ に分けて $\boldsymbol{P}_{01}$、$\boldsymbol{P}_1\boldsymbol{P}_2$ を $t:(1-t)$ に分けて $\boldsymbol{P}_{12}$。

2段目：線分 $\boldsymbol{P}_{01}\boldsymbol{P}_{12}$ を $t:(1-t)$ に分けた点が $\boldsymbol{P}(t)$。

$$\begin{aligned}\boldsymbol{P}(t)&=(1-t)\boldsymbol{P}_{01}+t\boldsymbol{P}_{12}\\&=(1-t)^2\boldsymbol{P}_0+2(1-t)t\,\boldsymbol{P}_1+t^2\boldsymbol{P}_2\end{aligned}$$

3次ベジェ曲線（点4個）：内分を3段重ねる

1段目：3本の線分から $\boldsymbol{P}_{01},\boldsymbol{P}_{12},\boldsymbol{P}_{23}$。2段目：その2本の線分から $\boldsymbol{P}_{012},\boldsymbol{P}_{123}$。3段目：最後の1本を $t:(1-t)$ に分けて $\boldsymbol{P}(t)$。

$$\begin{aligned}\boldsymbol{P}(t)&=(1-t)\boldsymbol{P}_{012}+t\boldsymbol{P}_{123}\\&=(1-t)^3\boldsymbol{P}_0+3(1-t)^2t\,\boldsymbol{P}_1\\&\quad+3(1-t)t^2\boldsymbol{P}_2+t^3\boldsymbol{P}_3\end{aligned}$$

段数を重ねるほど、$(1-t)$ と $t$ のかけ算が増えて式の次数が上がります。 $n$ 段（$n+1$ 個の点）で $t$ の $n$ 次多項式 になり、係数には二項係数が現れます。

5ラグランジュ補間とデータサイエンス

これまでは「式」から「グラフ」を作りました。逆に、与えられた点をすべて通る多項式 を作るにはどうすればよいでしょうか。

定理：$n$ 個の点を通る多項式

$x$ 座標がすべて異なる $n$ 個の点 $(x_1,y_1),\dots,(x_n,y_n)$ に対し、これらをすべて通る $(n-1)$ 次以下の多項式 がただ1つ存在する。 （2点 → 直線（1次）、3点 → 放物線（2次）、4点 → 3次…）

5.1ラグランジュ補間多項式

アイデアは、「点 $x_i$ でだけ $1$、ほかの点 $x_j$（$j\neq i$）では $0$」となる多項式 $L_i(x)$ を先に作ることです。 すると $y_i\,L_i(x)$ は「点 $(x_i,y_i)$ を通り、ほかの点では $0$」になるので、これらを足し合わせれば すべての点を通る多項式 $P(x)$ ができます。

2点のとき、$L_1(x)=\dfrac{x-x_2}{x_1-x_2}$、$L_2(x)=\dfrac{x-x_1}{x_2-x_1}$ です。 $x=(1-t)x_1+t\,x_2$ とおくと $L_1=1-t,\ L_2=t$ となり、1.2節の補間 $(1-t)\boldsymbol{A}+t\boldsymbol{B}$ と同じ です。

下の図で点の数（2〜4）を切り替えて、式と図の対応を確かめましょう。 分子は「自分以外の点で $0$ にする」ための因数、分母は「$x=x_i$ でちょうど $1$ にする」ための調整です。 式の中の 赤い文字 $x$ が変数 です。

5.2データサイエンスとの関係：補間・回帰・過学習

データ点を通る曲線を作ることは、次のような場面で使われます。

  • 補間：測定していない点の値を推定する（欠測値の補完、センサ値の間引き・再構成、画像の拡大縮小）。
  • 数値計算：関数を多項式で近似して、微分・積分を計算する。
  • 回帰：実際のデータには測定誤差（ランダムなずれ）がある。すべての点を通す必要はなく、全体の傾向 をつかみたい。 そこで次数 $m$ を決め、各データ点と曲線との縦のずれを2乗して足した値（二乗誤差の合計）が最も小さい $m$ 次多項式を選ぶ。これが最小二乗法（多項式回帰）。

ここで大切な落とし穴が 過学習 です。次数を上げるほど、手元のデータ（訓練データ）とのずれは必ず小さくなり、 $10$ 点に対して $9$ 次にするとラグランジュ補間そのもの（ずれ $0$）になります。 しかしそれは「測定誤差までまるごと覚えた」状態で、本当の傾向 からは大きくずれてしまいます。

読み取ろう
  • 赤い縦線は、次数を上げるほど 短くなり続け、$m=9$ では消える（訓練誤差 $0$）。
  • 一方 青緑の帯（本当の傾向とのずれ）は、ちょうどよい次数で最も細くなり、そこを超えると 太くなる。$m=9$ では青い線が暴れて、帯が大きく広がる。
  • 「データにぴったり合う」ことと「予測が当たる」ことは別。モデルの複雑さ（次数）を選ぶ ことが、データサイエンス・機械学習の中心課題のひとつです。
考えてみよう：データを取り直すと最適な次数は変わる？

「データを取り直す」を何度か押して、青緑の帯が最も細くなる次数を観察しましょう。誤差の出方が変わっても、だいたい低めの次数（3〜5次付近）が安定して良く、$m=9$ はほぼ毎回大きく暴れるはずです。「本当の傾向に最も近い次数にする」ボタンで確かめられます。

復習問題（クリックで表示）
  1. $y=x^2$ を $x$ 方向に $3$、$y$ 方向に $-2$ だけ平行移動したグラフの式を、$y-q=(x-p)^2$ の形で書け。
  2. $y=2x^2-8x+5$ の頂点を平方完成で求めよ。
  3. $\boldsymbol{A}=(0,0)$, $\boldsymbol{B}=(6,3)$ のとき、$t=\tfrac13$ の点 $\boldsymbol{P}(t)$ を求めよ。また $\mathrm{AP}:\mathrm{PB}$ はいくつか。
  4. smoothstep $f(t)=3t^2-2t^3$ について $f(0),\ f(1),\ f'(0),\ f'(1)$ を求めよ。
  5. 3点 $(0,1),\ (1,3),\ (2,7)$ を通る二次関数を求めよ。

答え：(1) $y+2=(x-3)^2$、すなわち $p=3,\ q=-2$　(2) $y=2(x-2)^2-3$ より頂点 $(2,-3)$　(3) $(2,1)$、$\mathrm{AP}:\mathrm{PB}=1:2$　(4) $0,\ 1,\ 0,\ 0$　(5) $y=x^2+x+1$
