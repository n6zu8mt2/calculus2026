1.4イージング

この節のゴール
  1. 位置の関数 $f(t)$ のグラフの傾きが「速さ」を表すことを説明できる。
  2. 出だしの速さ $v_0$ と終わりの速さ $v_1$ から、3次のイージング関数を作れる。
図 3つ ・ チャレンジ 4ステージ ・ 確認問題 3問

この節で使うこと：1.1節の 傾き（$x$ が $1$ 増えたときの $y$ の変化）と補間 $(1-t)\boldsymbol{A}+t\boldsymbol{B}$、1.2節の 二次関数のグラフ

スマホでメニューを開くとき、メニューは一定の速さで動くのではなく、勢いよく出てきて、最後はゆっくり止まります。 この「動きの緩急」を決めているのが、この節で学ぶイージング関数です。まずは実物を見比べてみましょう。

実例：スマホのメニューが開く動き 「メニューを開く」を押して、左右を見比べよう

実際のプログラムでは、次のように書きます。どれも「時間の割合 $t$（$0\to1$）を関数 $f$ に通してから位置を決める」という同じ考え方です。

Webページ（CSS）
.menu {
  transition: transform 0.3s ease-out;
}

ease-out の中身は 3次ベジェ曲線 cubic-bezier(0, 0, 0.58, 1)（1.5節）。

ゲーム（JavaScript）
// t: 経過時間の割合（0→1）
const f = t => 1 - (1 - t) ** 3;
x = start + (goal - start) * f(t);

1.1節(2) の補間の $t$ を $f(t)$ に置き換えただけ。

ゲームエンジン（Unity／C#）
float s = Mathf.SmoothStep(0f, 1f, t);
pos = Vector3.Lerp(a, b, s);

SmoothStep の中身は $3t^2-2t^3$（この節の smoothstep）。

このように、画面の中の物の動きは「時間の割合 $t$ ($0\to1$) から、位置（進み具合）$f(t)$ ($0\to1$) への関数」で決まっています。 これをイージング関数といいます。$f(t)=t$（一次関数）は等速ですが、機械的で不自然です。 2次・3次の多項式を使うと、ゆっくり動き出す（ease-in）、ゆっくり止まる（ease-out）動きが作れます。

覚える｜イージング関数

イージング関数 $f(t)$ とは、「時間がどれだけ経ったか」から「どれだけ進んだか」を決める関数

  • $t$＝経過時間の割合（スタートで $t=0$、ゴールの時刻で $t=1$）
  • $f(t)$＝進んだ距離の割合（スタート地点で $0$、ゴール地点で $1$）
  • スタートとゴールは必ず決まっているので $f(0)=0$、$f(1)=1$
  • $f(t)=t$ なら等速。途中の形を変えると、動きの緩急（速い・遅い）が変わる
身近なイージングの例
  • スマホの画面：メニューや通知がスッと出てきて、ゆっくり止まる。アプリを開くときに画面が広がる動き。
  • Webページのスクロール：目次のリンクを押すと、目的の場所まで滑らかに移動して止まる（このページの目次もそうです）。
  • プレゼンのアニメーション：PowerPoint などの「滑らかに開始」「滑らかに終了」という設定。
  • ゲーム：キャラクターの加速・減速、カメラがキャラクターを追いかける動き、ボタンを押したときに少し弾む動き。
  • 乗り物：エレベーターや電車は、急に動き出したり止まったりすると乗っている人が揺れるので、ゆっくり加速・減速するよう制御されている。

覚える｜速さ＝グラフの傾き

時刻 $t$ での速さは、グラフ $y=f(t)$ のその点での傾き

  • 傾きが急なところで速く、水平に近いところでゆっくり動く

この「グラフの傾き」を求める計算を微分といい、$f'(t)$ と書きます。微分は第4章で詳しく学びます。この節では「$f'(t)$＝その点でのグラフの傾き（速さ）」とだけ思っておけば十分です。

$\mathrm{smoothstep}\;3t^2-2t^3$ は、始まりと終わりで速さ（グラフの傾き）が $0$（$f'(0)=f'(1)=0$）になるよう調整した3次式です。

(2)3次関数でイージングを設計する

「出発するときの速さ $\amber{v_0}$」と「到着するときの速さ $\teal{v_1}$」を決めると、次の4条件を満たす3次多項式がただ1つに決まります。

覚える｜3次で設計する4つの条件
$$\begin{gathered}f(0)=0,\quad f(1)=1\\[2pt] f'(0)=v_0,\quad f'(1)=v_1\end{gathered}$$

$f'(0)$, $f'(1)$ は $t=0$, $t=1$ でのグラフの傾き（出だし・終わりの速さ）。微分の計算は4.2節で学びます（smoothstep の $f'(0)=f'(1)=0$ も確かめます）。

この4条件を満たす3次式は、次のようになります。

$$\begin{aligned}f(t) = {}&(\amber{v_0}+\teal{v_1}-2)\,t^3\\ &+ (3-2\amber{v_0}-\teal{v_1})\,t^2 + \amber{v_0}\,t\end{aligned}$$

上段の球の動きを見ながら、$v_0$（出だしの速さ）と $v_1$（終わりの速さ）を変えてみましょう。 グラフ上の矢印は、その点での傾き（＝速さ）を表します。

確認確認問題

  1. smoothstep $f(t)=3t^2-2t^3$ について、$f(0),\ f(1)$ を求めよ。また、図(1) のグラフから $t=0$, $t=1$ での傾き $f'(0),\ f'(1)$ を読み取れ。
  2. $f(t)=t^2$（easeInQuad）のとき、時間の半分 $t=\tfrac12$ で、全体のどれだけ進んでいるか。
  3. 1.4節(2) の式 $$f(t)=(v_0+v_1-2)t^3+(3-2v_0-v_1)t^2+v_0t$$ で、$v_0=v_1=0$ とするとどうなるか。
答え（クリックで表示）
  1. $f(0)=3\times0^2-2\times0^3=0$、$f(1)=3\times1^2-2\times1^3=1$。
    図(1) の smoothstep のグラフは $t=0$ と $t=1$ で水平（傾き $0$）なので $f'(0)=0$、$f'(1)=0$
  2. $f\!\left(\tfrac12\right)=\left(\tfrac12\right)^2=\tfrac14$。
    時間の半分で、全体の $\tfrac14$ しか進んでいない（前半はゆっくり）
  3. $v_0=v_1=0$ を代入すると $(0+0-2)t^3+(3-0-0)t^2+0\times t$。
    よって $f(t)=-2t^3+3t^2$（smoothstep と同じ）
