1.4イージング

この章のゴール
  1. 位置の関数 $f(t)$ のグラフの傾きが「速さ」を表すことを説明できる。
  2. 出だしの速さ $v_0$ と終わりの速さ $v_1$ から、3次のイージング関数を作れる。
図 3つ ・ チャレンジ 4ステージ ・ 確認問題 3問

スマホでメニューを開くとき、メニューは一定の速さで動くのではなく、勢いよく出てきて、最後はゆっくり止まります。 この「動きの緩急」を決めているのが、この章で学ぶ イージング関数 です。まずは実物を見比べてみましょう。

実例：スマホのメニューが開く動き 「メニューを開く」を押して、左右を見比べよう

実際のプログラムでは、次のように書きます。どれも「時間の割合 $t$（$0\to1$）を関数 $f$ に通してから位置を決める」という同じ考え方です。

Webページ（CSS）
.menu {
  transition: transform 0.3s ease-out;
}

ease-out の中身は 3次ベジェ曲線 cubic-bezier(0, 0, 0.58, 1)（1.5章）。

ゲーム（JavaScript）
// t: 経過時間の割合（0→1）
const f = t => 1 - (1 - t) ** 3;
x = start + (goal - start) * f(t);

1.1章(2) の補間の $t$ を $f(t)$ に置き換えただけ。

ゲームエンジン（Unity／C#）
float s = Mathf.SmoothStep(0f, 1f, t);
pos = Vector3.Lerp(a, b, s);

SmoothStep の中身は $3t^2-2t^3$（この章の smoothstep）。

このように、画面の中の物の動きは「時間の割合 $t$ ($0\to1$) から、位置（進み具合）$f(t)$ ($0\to1$) への関数」で決まっています。 これを イージング関数 といいます。$f(t)=t$（一次関数）は 等速 ですが、機械的で不自然です。 2次・3次の多項式を使うと、ゆっくり動き出す（ease-in）、ゆっくり止まる（ease-out） 動きが作れます。

身近なイージングの例
  • スマホの画面：メニューや通知がスッと出てきて、ゆっくり止まる。アプリを開くときに画面が広がる動き。
  • Webページのスクロール：目次のリンクを押すと、目的の場所まで滑らかに移動して止まる（このページの目次もそうです）。
  • プレゼンのアニメーション：PowerPoint などの「滑らかに開始」「滑らかに終了」という設定。
  • ゲーム：キャラクターの加速・減速、カメラがキャラクターを追いかける動き、ボタンを押したときに少し弾む動き。
  • 乗り物：エレベーターや電車は、急に動き出したり止まったりすると乗っている人が揺れるので、ゆっくり加速・減速するよう制御されている。

$f(t)$ のグラフの 傾き $f'(t)$ が、その瞬間の 速さ です。傾きが急なところで速く、水平に近いところでゆっくり動きます。 $\mathrm{smoothstep}\;3t^2-2t^3$ は、始まりと終わりで速さが $0$（$f'(0)=f'(1)=0$）になるよう調整した3次式です。

(2)3次関数でイージングを設計する

「出発するときの速さ $\amber{v_0}$」と「到着するときの速さ $\teal{v_1}$」を決めると、次の4条件を満たす3次多項式がただ1つに決まります。

$$f(0)=0,\quad f(1)=1,\quad f'(0)=\amber{v_0},\quad f'(1)=\teal{v_1}$$ $$f(t) = (\amber{v_0}+\teal{v_1}-2)\,t^3 + (3-2\amber{v_0}-\teal{v_1})\,t^2 + \amber{v_0}\,t$$

上段の 球の動き を見ながら、$v_0$（出だしの速さ）と $v_1$（終わりの速さ）を変えてみましょう。 グラフ上の矢印は、その点での 傾き（＝速さ） を表します。
