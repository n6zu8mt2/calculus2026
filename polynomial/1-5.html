1.5ベジェ曲線

この節のゴール
  1. $t:(1-t)$ の内分を重ねるとベジェ曲線が描けること（ド・カステリョのアルゴリズム）を説明できる。
  2. CSS の cubic-bezier(x1, y1, x2, y2) の4つの数が何を表すか説明できる。
図 4つ ・ チャレンジ 4ステージ ・ 確認問題 3問

この節で使うこと：1.1節の 補間 $\boldsymbol{P}(t)=(1-t)\boldsymbol{A}+t\boldsymbol{B}$（線分を $t:(1-t)$ に分ける点）、1.4節の イージング

パソコンやスマホに表示される文字の形（フォント）、イラストソフトで描く線、Webページのアイコン。 これらのなめらかな曲線の多くは、ベジェ曲線という多項式の曲線をつないで作られています。 まずは実例を見てみましょう。

実例：3次ベジェ曲線4本で描いたハート 四角 ＝ 端点丸 ＝ 制御点 制御点をドラッグすると形が変わる

四角は曲線の 端点、丸は形を決める 制御点 です。曲線は制御点を通りませんが、制御点の方へ引っ張られます。

このハートを SVG（Webの画像形式）で書くと次のとおりです。C が「3次ベジェ曲線を描く」という命令です。

ベジェ曲線が使われているところ
  • フォント（文字の形）：文字の輪郭はベジェ曲線をつないで記録されている（TrueType 形式は2次、OpenType の CFF 形式は3次）。点の座標だけを保存しているので、どれだけ拡大してもギザギザにならない。
  • イラスト・デザイン：Illustrator や Figma の「ペンツール」、Web の SVG 画像（上の C 命令）。
  • アニメーション：CSS の cubic-bezier() で動きの緩急を指定する（この節の(3)、1.4節のイージング）。
  • 工業デザイン：自動車のボディのなめらかな曲面の設計。もともとルノーの技術者ピエール・ベジェが考案した。

1.1節(2)の補間 $\boldsymbol{P}(t)=(1-t)\boldsymbol{A}+t\boldsymbol{B}$ を繰り返すと曲線が生まれます。 制御点 $\boldsymbol{P}_0,\dots,\boldsymbol{P}_n$ があるとき、次の操作を1点になるまで続けます（ド・カステリョのアルゴリズム）。

覚える｜ド・カステリョの操作（ベジェ曲線の作り方）

同じ $t$（$0\leqq t\leqq1$）で、となり合う2点の間を $t:(1-t)$ に分ける点をとる。
点が1つ減るので、これを点が1つになるまでくり返す。最後に残った点が曲線上の点 $\boldsymbol{P}(t)$。

$$\boldsymbol{X}\ \text{と}\ \boldsymbol{Y}\ \text{を}\ t:(1-t)\ \text{に分ける点}=(1-t)\boldsymbol{X}+t\boldsymbol{Y}$$
  • 例（制御点が3個 $\boldsymbol{P}_0,\boldsymbol{P}_1,\boldsymbol{P}_2$）：
    ① $\boldsymbol{P}_0\boldsymbol{P}_1$、$\boldsymbol{P}_1\boldsymbol{P}_2$ をそれぞれ $t:(1-t)$ に分ける点 $\boldsymbol{Q}_0,\ \boldsymbol{Q}_1$ をとる（3個 → 2個）
    ② $\boldsymbol{Q}_0\boldsymbol{Q}_1$ を同じ $t:(1-t)$ に分ける点 $\boldsymbol{R}$ をとる（2個 → 1個）。これが $\boldsymbol{P}(t)$
  • $t$ を $0$ から $1$ まで動かしたときに $\boldsymbol{P}(t)$ が描く跡が ベジェ曲線。
  • $t=0$ では $\boldsymbol{P}(0)=\boldsymbol{P}_0$、$t=1$ では最後の制御点になる（曲線は両端の制御点を通る）。

この点は、$\boldsymbol{X}$ からの距離が全体の $t$ 倍の点です。線分 $\boldsymbol{X}\boldsymbol{Y}$ は $\boldsymbol{X}$ 側の長さ $=t$（赤）と $\boldsymbol{Y}$ 側の長さ $=1-t$（青緑）に分かれます。 どの線分でも、同じ $t$ で同じ比に分けます。

(1)1次から3次のベジェ曲線：$t:(1-t)$ がどこに現れるか

まずは1次から3次まで、それぞれ図で確かめましょう。図ごとに再生／停止と $t$ のスライダーがあります。 $t$ を動かすと、すべての線分が赤と青緑に同じ比 $t:(1-t)$ で分かれることが見えます。 内分を重ねるほど、線は細く薄く描いています（薄い線ほど後の段）。点はドラッグできます。

1次・2次・3次のベジェ曲線 点をドラッグ／再生・停止と t は各図の下
赤：$t$ の長さ（手前側） 青緑：$1-t$ の長さ（向こう側） 青：ベジェ曲線と、いま求めている点 P(t) 薄い線ほど、あとの段の内分

1次ベジェ曲線（点2個）：線分

$\boldsymbol{P}_0\boldsymbol{P}_1$ を $t:(1-t)$ に内分した点が $\boldsymbol{P}(t)$。1.1節(2)の補間そのものです。

$$\boldsymbol{P}(t)=(1-t)\boldsymbol{P}_0+t\boldsymbol{P}_1$$

$\overline{\boldsymbol{P}_0\boldsymbol{P}}=t\,\overline{\boldsymbol{P}_0\boldsymbol{P}_1}$、$\overline{\boldsymbol{P}\boldsymbol{P}_1}=(1-t)\,\overline{\boldsymbol{P}_0\boldsymbol{P}_1}$。

2次ベジェ曲線（点3個）：内分を2段重ねる

1段目：$\boldsymbol{P}_0\boldsymbol{P}_1$ を $t:(1-t)$ に分けて $\boldsymbol{P}_{01}$、$\boldsymbol{P}_1\boldsymbol{P}_2$ を $t:(1-t)$ に分けて $\boldsymbol{P}_{12}$。

2段目：線分 $\boldsymbol{P}_{01}\boldsymbol{P}_{12}$ を $t:(1-t)$ に分けた点が $\boldsymbol{P}(t)$。

$$\begin{aligned}\boldsymbol{P}(t)&=(1-t)\boldsymbol{P}_{01}+t\boldsymbol{P}_{12}\\&=(1-t)^2\boldsymbol{P}_0+2(1-t)t\,\boldsymbol{P}_1+t^2\boldsymbol{P}_2\end{aligned}$$

3次ベジェ曲線（点4個）：内分を3段重ねる

1段目：3本の線分から $\boldsymbol{P}_{01},\boldsymbol{P}_{12},\boldsymbol{P}_{23}$。2段目：その2本の線分から $\boldsymbol{P}_{012},\boldsymbol{P}_{123}$。3段目：最後の1本を $t:(1-t)$ に分けて $\boldsymbol{P}(t)$。

$$\begin{aligned}\boldsymbol{P}(t)&=(1-t)\boldsymbol{P}_{012}+t\boldsymbol{P}_{123}\\&=(1-t)^3\boldsymbol{P}_0+3(1-t)^2t\,\boldsymbol{P}_1\\&\quad+3(1-t)t^2\boldsymbol{P}_2+t^3\boldsymbol{P}_3\end{aligned}$$
覚える｜2次・3次のベジェ曲線
$$\begin{aligned}\boldsymbol{P}(t)&=(1-t)^2\boldsymbol{P}_0+2(1-t)t\,\boldsymbol{P}_1+t^2\boldsymbol{P}_2\\[8pt] \boldsymbol{P}(t)&=(1-t)^3\boldsymbol{P}_0+3(1-t)^2t\,\boldsymbol{P}_1\\&\quad+3(1-t)t^2\boldsymbol{P}_2+t^3\boldsymbol{P}_3\end{aligned}$$

段数を重ねるほど、$(1-t)$ と $t$ のかけ算が増えて式の次数が上がります。 $n$ 段（$n+1$ 個の点）で $t$ の $n$ 次多項式になり、係数には二項係数が現れます。

(2)好きな次数で曲線をデザインする

次数を1〜8次から選べます。制御点をドラッグして形を作り、重み（棒グラフ）と基底関数の関係を観察しましょう。

覚える｜$n$ 次のベジェ曲線

$n+1$ 個の制御点 $\boldsymbol{P}_0,\ \boldsymbol{P}_1,\ \dots,\ \boldsymbol{P}_n$ で「$t:(1-t)$ に内分」を $n$ 回くり返してできる曲線

  • $\boldsymbol{P}_i$ にかかる重みは「$(1-t)$ を $n-i$ 個」と「$t$ を $i$ 個」かけたものに、係数 をつけたもの。
  • 係数は、2次で計算するとわかります。$\boldsymbol{Q}_0=(1-t)\boldsymbol{P}_0+t\boldsymbol{P}_1$、$\boldsymbol{Q}_1=(1-t)\boldsymbol{P}_1+t\boldsymbol{P}_2$ を使うと $$\begin{aligned}\boldsymbol{P}(t)&=(1-t)\boldsymbol{Q}_0+t\,\boldsymbol{Q}_1\\&=(1-t)^2\boldsymbol{P}_0+\underbrace{(1-t)t+t(1-t)}_{2(1-t)t}\,\boldsymbol{P}_1+t^2\boldsymbol{P}_2\end{aligned}$$ $\boldsymbol{P}_1$ には「$\boldsymbol{Q}_0$ 経由」と「$\boldsymbol{Q}_1$ 経由」の 2通りの道 があるので係数が $2$ になります。
  • 一般に、係数は「$\boldsymbol{P}_i$ にたどり着く道の数」。1段ごとに左上か右上の2つから来るので、上の2つの数の和 を並べた パスカルの三角形 になります。
    1次：$1,\,1$　2次：$1,\,2,\,1$　3次：$1,\,3,\,3,\,1$　4次：$1,\,4,\,6,\,4,\,1$
    （この数は二項係数 ${}_n\mathrm{C}_i$ と同じで、$(a+b)^n$ を展開したときの係数でもあります）
  • 曲線の $x$ 座標も $y$ 座標も、$t$ の $n$ 次多項式。

$\boldsymbol{P}_i$ にかかる重みを $B_{n,i}(t)$ と書きます（上の図の「重み関数」）。たとえば4次のベジェ曲線は

$$\begin{aligned}\boldsymbol{P}(t)={}&(1-t)^4\boldsymbol{P}_0+4(1-t)^3t\,\boldsymbol{P}_1\\&+6(1-t)^2t^2\boldsymbol{P}_2\\&+4(1-t)t^3\boldsymbol{P}_3+t^4\boldsymbol{P}_4\end{aligned}$$
ポイント：曲線の座標は $t$ の多項式

$B_{n,i}(t)$ は $t$ の $n$ 次多項式で、$t$ を動かしたときの重みの合計はいつも $1$ です（棒グラフの合計）。 つまり $\boldsymbol{P}(t)$ は制御点の重みつき和で、曲線は制御点の作る多角形の内側に収まります。 $x$ 座標も $y$ 座標も、それぞれ $t$ の $n$ 次多項式です。

触ってみよう
  • 曲線は端点 $\boldsymbol{P}_0$, $\boldsymbol{P}_n$ を通る。途中の点は通らないが、引っ張られる。
  • $t=0$ のとき、曲線は最初の線分 $\boldsymbol{P}_0\boldsymbol{P}_1$ の向きに動き出す。
  • 次数を上げると曲線はどう変わる？　1点を動かしたとき、曲線全体に影響が及ぶ範囲は？

(3)ベジェ曲線とイージングの関係（CSS の cubic-bezier()）

1.4節(2)のイージングは、$x$ 軸を「時間」、$y$ 軸を「位置」とみなした3次ベジェ曲線でした。 始点 $(0,0)$ と終点 $(1,1)$ を固定し、2つの制御点 $(x_1,y_1)$, $(x_2,y_2)$ だけを指定する書き方が Webページの transition-timing-function: cubic-bezier(x1, y1, x2, y2) です。 下の図の 青い球 は上のグラフから計算した位置、青緑の球 はブラウザのCSSが動かしたものです。両者は一致します。

cubic-bezier エディタ 金 ＝ $P_1$緑 ＝ $P_2$ 2つのつまみをドラッグ（時間 $x$ は $0\sim1$ に制限）
CSS の transition で動かした球（ブラウザの実装）
注意

$y_1$, $y_2$ を $[0,1]$ の外に出すと、目的地を行き過ぎてから戻る（オーバーシュート）動きになります。 一方 $x_1$, $x_2$ を $[0,1]$ の外に出すと、時間が逆戻りする場合があるため CSS では許されません。

  1. $\boldsymbol{P}_0=(0,0)$, $\boldsymbol{P}_1=(2,4)$, $\boldsymbol{P}_2=(4,0)$ の2次ベジェ曲線で、$t=\tfrac12$ の点を求めよ。
  2. 3次のベルンシュタイン基底 $B_{3,1}(t)=3(1-t)^2t$ について、$B_{3,1}(\tfrac12)$ を求めよ。
  3. cubic-bezier(0, 0, 1, 1) はどんな動きになるか。
答え（クリックで表示）
  1. $t=\tfrac12$ なので、中点をとることを2回くり返す。$\boldsymbol{P}_0\boldsymbol{P}_1$ の中点 $(1,\ 2)$、$\boldsymbol{P}_1\boldsymbol{P}_2$ の中点 $(3,\ 2)$。
    その2点の中点で $(2,\ 2)$（式では $\tfrac14\boldsymbol{P}_0+\tfrac12\boldsymbol{P}_1+\tfrac14\boldsymbol{P}_2=(2,\ 2)$）
  2. $B_{3,1}\!\left(\tfrac12\right)=3\times\left(1-\tfrac12\right)^2\times\tfrac12=3\times\tfrac14\times\tfrac12=\tfrac38$
  3. 4つの制御点は $(0,0),\ (0,0),\ (1,1),\ (1,1)$ で、すべて直線 $y=x$ 上にある。
    よって曲線も $y=x$ そのもので、等速（linear と同じ）
